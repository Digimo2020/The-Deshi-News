## 🎨 Design Guidelines for Screenshots

### Color Scheme
- **Primary Red**: #CC0000 (TheDesi.news brand)
- **Portuguese Blue**: #002868
- **Neutral**: Grays and whites for clarity
- **Accent**: Greens, blues for interactive elements

### Typography
- **Headlines**: Bold, clear, readable
- **Body Text**: Sans-serif, 14-16px
- **UI Text**: High contrast for accessibility

### Visual Elements
- ✅ Include diverse representation
- ✅ Show multilingual interface (text in different scripts)
- ✅ Realistic data/content
- ✅ Clear navigation and buttons
- ✅ Professional, modern design
- ✅ Accessibility indicators (alt text, captions)

### Layout Standards
- Consistent spacing and alignment
- Clear visual hierarchy
- Readable without zoom
- Mobile/responsive hints where applicable
- Consistent branding

## 📋 Screenshot Creation Checklist

### For Each Screenshot:
- [ ] Correct dimensions (1200 x 800px for features, 1920 x 600px for hero)
- [ ] Brand colors applied correctly
- [ ] Professional, clean layout
- [ ] Realistic sample data/content
- [ ] Multilingual support visible where relevant
- [ ] Call-to-action buttons clear
- [ ] Images compressed optimized (< 500KB each)
- [ ] Consistent naming convention
- [ ] File format: PNG (quality 90%)

### Quality Checks:
- [ ] No placeholder text visible
- [ ] All text readable and spellchecked
- [ ] Proper contrast ratio for accessibility (WCAG AA)
- [ ] No personally identifiable information shown
- [ ] Responsive design hints if applicable
- [ ] Brand guidelines followed
- [ ] Dates/information are current

### Markdown Syntax:
```markdown
![Feature Name Screenshot](./assets/features/feature-name.png)
```

### Best Practices:
1. Always include alt text (description between brackets)
2. Use descriptive filenames
3. Keep file sizes optimized
4. Store in organized directories
5. Update README when adding screenshots
6. Include screenshots in git commits
